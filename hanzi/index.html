中文字工作紙生成器

輸入默書字詞 → 一鍵產生六步寫字工作紙（Word · A4 · 每字 2 頁）

進階：手動指定部件（可選）

程式會自動拆部件；如果某個字拆得不理想，在這裡加一行即可，格式：字 = 部件,部件 或 字 = 筆畫數,筆畫數

輸入要練習的字，再按「產生工作紙」。

工作紙包含

  1. 目標字：三格示範 —— 無輔助線／九格線／米字線
  2. 分拆部首部件：不同部件不同顏色
  3. 已拆細的部件：按筆順次序排列，顏色與上一步相同
  4. 筆順展示：一格加一筆，自動計算格數
  5. 按筆順順序謄寫：4.8 → 3.6 → 2.4 → 1.2cm，首格淺灰示範字可描寫
  6. 隱藏部件默寫：灰色長方形標示隱藏位置，逐步增加難度
  7. 默寫字詞：首兩格附十字輔助線

字形以楷書筆順資料繪製，筆順與部件結構依標準字形；資料來源：hanzi-writer-data、cjkvi-ids、kfcd/chaizi。第一次使用需連網讀取筆順。
